SCORM BuilderĐóng gói khóa học e-learning cho Workday

Chọn thư mục khóa học (chứa video và file Excel). Mọi thứ chạy ngay trên máy bạn: video và đề thi không được tải lên đâu cả.

1Chọn thư mục khóa

Chưa chọn

Chọn thư mục chứa video của khóa (video nằm trong các thư mục con cũng được). Builder tự tìm file Excel trong thư mục. File Excel chưa cần điền xong: cứ sửa dần, lưu lại rồi bấm Kiểm tra lại ở bước 3.

Trình duyệt có thể hỏi "Cho phép xem tệp?" hoặc "Tải lên?": cứ đồng ý, file vẫn chỉ nằm trên máy bạn.

Chưa có file Excel? Tải file Excel mẫu, lưu vào thư mục khóa.

Không chọn = dùng logo Coteccons có sẵn
